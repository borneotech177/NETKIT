Kalkulator subnet

Fungsi: membagi satu jaringan menjadi bagian lebih kecil dan menunjukkan batas-batasnya.

  1. Ketik alamat IP diikuti /prefix, contoh 192.168.10.37/26.
  2. Hasil muncul otomatis saat mengetik.

Cara membaca hasil:

  • Network: alamat jaringan itu sendiri, tidak dipakai perangkat.
  • Broadcast: alamat siaran ke semua perangkat, juga tidak dipakai perangkat.
  • Host pertama - terakhir: rentang IP yang boleh dipasang ke perangkat.
  • Wildcard: kebalikan netmask, dipakai di ACL Cisco dan OSPF.

Contoh: /24 = 255.255.255.0 = 254 host. Makin besar angka prefix, makin kecil jaringannya.

VLSM

Fungsi: membagi satu network induk menjadi beberapa subnet dengan ukuran berbeda sesuai kebutuhan, supaya IP tidak terbuang.

  1. Isi Network induk, misalnya 192.168.0.0/24.
  2. Tulis kebutuhan, satu baris satu subnet, format nama:jumlah host.
  3. Tekan Hitung.

Alokasi dimulai dari kebutuhan terbesar. Alamat network dan broadcast sudah dihitung otomatis, jadi isi jumlah perangkat sebenarnya.

Tips: tambahkan cadangan 20-30% untuk pertumbuhan perangkat. Kalau muncul pesan ruang tidak cukup, pakai network induk yang lebih besar.

Generator konfigurasi

Fungsi: membuat perintah konfigurasi siap tempel untuk MikroTik atau Cisco.

  1. Pilih Perangkat dan Jenis.
  2. Isi network LAN dalam format CIDR, nama interface, dan DNS.
  3. Tekan Buat konfigurasi, lalu Salin.
  4. Tempel di terminal MikroTik atau console Cisco.
  • VLAN + DHCP: memisahkan jaringan secara logis (misal CCTV terpisah dari kantor). Gateway otomatis memakai IP pertama, pool DHCP mulai dari .10.
  • NAT internet: membuat jaringan LAN bisa keluar ke internet lewat interface WAN.
  • Firewall dasar: memblokir akses dari luar, hanya LAN yang boleh mengakses router.

Hati-hati: samakan nama interface dengan perangkat asli, backup konfigurasi dulu, dan jangan coba firewall di router produksi tanpa akses fisik karena bisa terkunci.

Isi data di atas, lalu tekan Buat konfigurasi.

Konversi

Fungsi: mengubah angka antar format. Berguna untuk belajar biner, karena IP sebenarnya adalah 4 kelompok 8 bit.

Contoh yang bisa diketik:

  • 192.168.1.1: IP menjadi desimal, hex, dan biner.
  • 24: ditampilkan juga sebagai netmask /24.
  • 0xC0A80101: hex menjadi IP.
  • 0b11000000: biner menjadi desimal.
  • 255.255.255.0: dikenali sebagai mask /24.

Catatan lapangan

Fungsi: mencatat temuan, IP, dan pekerjaan di lapangan.

  1. Isi judul, tag (opsional), dan isi catatan, lalu tekan Simpan catatan.
  2. Pakai kolom Cari untuk menyaring berdasarkan judul, isi, atau tag.

Penting: catatan hanya tersimpan di browser atau perangkat ini. Kalau data browser dihapus, catatan hilang. Tekan Ekspor JSON secara berkala untuk cadangan. Hapus catatan tidak bisa dibatalkan.

Uji koneksi

Fungsi: mengecek apakah sebuah perangkat bisa dijangkau dan berapa lama responnya.

  1. Isi host (IP atau domain), misalnya IP router 192.168.88.1.
  2. Tekan Cek HTTP.
  • respon xx ms: perangkat menjawab, angkanya waktu tempuh.
  • gagal / timeout: tidak terjangkau, atau tidak menjalankan layanan web.

Cek HTTP bukan ping ICMP asli, jadi perangkat harus punya layanan web aktif. Ping ICMP dan Cek port TCP hanya jalan di versi app (butuh plugin native).

Cek HTTP jalan di browser. Ping dan TCP butuh plugin native NetTools saat dikonversi ke app.

Sapu rentang IP

Mencari perangkat yang menjawab di port tertentu. Ini cek layanan web (bukan ping), jadi perangkat tanpa layanan di port itu tidak akan muncul.

Maksimal 254 alamat sekali sapu.

Dasar IP dan subnet

Alamat IPv4 terdiri dari 32 bit, ditulis 4 kelompok angka (oktet) 0-255. Netmask menentukan bagian mana yang network dan bagian mana yang host.

  • Perangkat dalam satu subnet bisa saling bicara langsung. Beda subnet harus lewat router (gateway).
  • Alamat pertama = network, terakhir = broadcast, tidak boleh dipasang ke perangkat.
  • Rumus jumlah host: 2^(32-prefix) - 2.

Model OSI dan TCP/IP
  1. Fisik: kabel, sinyal, konektor.
  2. Data link: MAC address, switch, VLAN.
  3. Network: IP, router, ICMP (ping).
  4. Transport: TCP dan UDP, nomor port.
  5. Session, 6. Presentation, 7. Aplikasi: HTTP, DNS, DHCP, dll.

Cara pakai saat troubleshooting: mulai dari bawah. Kabel lepas (lapisan 1) sering jadi penyebab masalah yang tampak rumit.

VLAN

VLAN memisahkan jaringan secara logis di switch yang sama. Contoh: CCTV, kantor, dan WiFi tamu masing-masing satu VLAN sehingga tidak saling campur.

  • Access port: untuk perangkat akhir (PC, kamera), membawa satu VLAN tanpa tag.
  • Trunk port: antar switch atau ke router, membawa banyak VLAN dengan tag 802.1Q.
  • Antar VLAN tidak bisa saling akses kecuali lewat router (inter-VLAN routing) dan aturan firewall mengizinkan.
  • Rentang ID 1-4094. VLAN 1 biasanya default, hindari dipakai untuk data penting.
DHCP

DHCP memberi IP otomatis ke perangkat. Prosesnya DORA: Discover, Offer, Request, Acknowledge.

  • Server memberi IP, netmask, gateway, dan DNS.
  • Pool jangan menimpa IP statis (gateway, server, kamera, printer).
  • Perangkat penting sebaiknya pakai static lease (IP tetap berdasarkan MAC).
  • Dapat IP 169.254.x.x berarti DHCP gagal.
DNS

DNS menerjemahkan nama (contoh: google.com) menjadi IP. Kalau ping IP berhasil tetapi ping nama gagal, masalahnya di DNS.

  • DNS publik umum: 8.8.8.8 (Google), 1.1.1.1 (Cloudflare).
  • Di MikroTik, aktifkan allow-remote-requests=yes agar router jadi DNS server untuk LAN.
NAT

NAT mengubah IP privat menjadi IP publik saat keluar ke internet, sehingga banyak perangkat berbagi satu IP publik.

  • Masquerade / overload: untuk akses internet dari LAN (srcnat).
  • Port forward / dst-nat: membuka layanan di dalam LAN ke luar, misalnya akses CCTV dari internet. Batasi dan amankan, jangan buka port sembarangan.
Routing dan gateway
  • Gateway: router tempat paket dikirim jika tujuan di luar subnet.
  • Default route 0.0.0.0/0: jalur untuk semua tujuan yang tidak dikenal, biasanya ke ISP.
  • Static route: jalur manual ke jaringan tertentu. Contoh MikroTik: /ip route add dst-address=192.168.20.0/24 gateway=192.168.10.2
  • Routing harus dua arah: tujuan juga harus tahu jalan pulang.
Firewall dan ACL
  • Aturan dibaca berurutan dari atas, aturan pertama yang cocok dipakai.
  • Pola aman: izinkan established,related, drop invalid, izinkan yang perlu, drop sisanya.
  • Input: lalu lintas ke router. Forward: lalu lintas melewati router.
  • Selalu pastikan akses admin Anda diizinkan sebelum menambah aturan drop terakhir.

Troubleshooting berurutan
  1. Fisik: kabel, lampu link, port, adaptor daya.
  2. IP: apakah dapat IP yang benar? Cek ipconfig atau ip a.
  3. Gateway: ping IP gateway.
  4. Internet: ping 8.8.8.8. Gagal = masalah routing, NAT, atau ISP.
  5. DNS: ping google.com. Gagal padahal langkah 4 berhasil = masalah DNS.
  6. Layanan: cek port aplikasi dan firewall.

Perintah berguna

Windows / Linux

  • ping 192.168.1.1: cek jangkauan.

Cisco

  • copy running-config startup-config: simpan konfigurasi.

Hitung kebutuhan CCTV

Dipakai sebelum membeli perangkat: berapa bandwidth, kapasitas hard disk, daya PoE, dan IP yang dibutuhkan untuk sejumlah kamera.

  1. Isi jumlah kamera dan bitrate per kamera. Bitrate ada di menu pengaturan kamera atau NVR (kira-kira 2-4 Mbps untuk 2 MP, 4-8 Mbps untuk 4 MP, tergantung kompresi).
  2. Isi jam rekam per hari dan lama penyimpanan.
  3. Isi daya per kamera dan budget PoE switch (lihat spesifikasi switch).
  4. Tekan Hitung.

Kapasitas hard disk sudah ditambah cadangan 20%. Hasilnya perkiraan, rekaman deteksi gerak biasanya lebih hemat.

Daftar IP (IPAM)

Buku catatan IP: siapa memakai alamat mana. Tujuannya mencegah IP bentrok dan memudahkan serah terima ke teknisi lain.

  1. Isi IP dan nama perangkat. Tipe, lokasi, dan MAC boleh dikosongkan.
  2. Tekan Simpan. Kalau IP sudah ada, aplikasi menolak dan menunjukkan pemakainya.
  3. Cari dengan kolom pencarian, ekspor CSV untuk dibuka di Excel.

Data hanya di perangkat ini. Ekspor berkala sebagai cadangan.

Urutan kabel UTP

Panduan memasang konektor RJ45. Pilih jenis kabel, lihat urutan warna di tiap ujung.

  • Straight: kedua ujung sama (T568B-T568B). Untuk PC ke switch, router ke switch.
  • Crossover: satu ujung T568A, satu ujung T568B. Perangkat modern umumnya sudah otomatis (Auto MDI-X), jadi straight biasanya cukup.

Posisi: kontak emas menghadap ke atas, klip konektor ke bawah, pin 1 di sisi kiri.

Langkah crimping

  1. Kupas selubung luar sekitar 1,5 cm.
  2. Urutkan 8 kabel sesuai warna, luruskan.
  3. Potong rata, sisakan sekitar 1 cm.
  4. Masukkan sampai ujung kabel menyentuh ujung konektor.
  5. Crimp dengan tang, pastikan selubung ikut tergigit.
  6. Tes dengan LAN tester: lampu 1-8 harus menyala berurutan.

Listrik dan UPS

Perhitungan dasar listrik 1 fasa. Hasilnya perkiraan awal, bukan pengganti perhitungan resmi atau PUIL.

  • Arus: I = P / (V x cos phi).
  • MCB: dipilih ukuran standar di atas arus beban, tapi tidak boleh melebihi kemampuan hantar arus kabel.
  • Drop tegangan: makin panjang dan makin kecil kabel, makin besar. Usahakan di bawah 3%.
  • UPS: pilih kapasitas VA di atas beban dengan cadangan 25%. Waktu cadangan tergantung kapasitas aki.

Port forward

Membuat aturan untuk membuka akses dari luar ke perangkat di LAN, misalnya NVR atau CCTV.

  1. Isi interface WAN, port yang dibuka di luar, IP perangkat tujuan, dan port tujuan.
  2. Salin hasilnya ke terminal router.

Waspada: membuka port langsung ke internet berisiko. Untuk CCTV lebih aman lewat VPN. Batasi alamat sumber kalau bisa, dan ganti password bawaan perangkat.

Isi data, lalu tekan Buat aturan.

Kumpulan perintah

Perintah yang sering dipakai, siap salin. Ketuk judul untuk membuka, tekan Salin, lalu tempel di terminal.

Ganti nilai contoh (IP, nama, interface) sesuai perangkat. Perintah MikroTik di sini untuk RouterOS v7, sebagian berbeda di v6.

Daftar port

Cari nomor port atau nama layanan. Berguna saat mengatur firewall atau port forward.

Port bertanda berisiko sebaiknya tidak dibuka langsung ke internet.

MAC address

Tempel MAC dalam format apa pun. Aplikasi menampilkan format umum (MikroTik, Cisco, polos) dan mencoba mengenali pabrikannya dari 3 byte awal (OUI).

Daftar pabrikan di sini kecil dan bisa tidak lengkap. Untuk kepastian, cek database OUI IEEE.

Buat sandi

Membuat password acak yang kuat, langsung di perangkat ini (tidak dikirim ke mana pun).

  • Untuk WiFi tamu, pakai panjang 12-16 tanpa simbol agar mudah diketik.
  • Untuk router dan NVR, pakai 16 karakter atau lebih dengan simbol.
  • Jangan pakai password yang sama untuk semua perangkat.

Denah CCTV

Menggambar denah, menaruh kamera, dan melihat sudut pandang serta jarak efektifnya sebelum memasang.

  1. Isi lebar dan tinggi area (meter). Boleh pasang gambar denah dari galeri, lalu sesuaikan lebar/tinggi agar skalanya pas.
  2. Dinding: seret di denah untuk menggambar tembok.
  3. Kamera: ketuk lokasi. Kerucut menunjukkan area pandang.
  4. Pilih: ketuk kamera untuk mengatur lensa, resolusi, dan arah. Seret kamera untuk memindah, seret titik putih di ujung kerucut untuk memutar.
  5. NVR: taruh lokasi NVR/switch, kabel tiap kamera dihitung otomatis.

Warna kerucut: hijau = wajah bisa diidentifikasi, kuning = orang bisa dikenali, biru = kejadian bisa diamati. Jarak dihitung dari lensa dan resolusi dengan standar kepadatan piksel (250, 125, 62 piksel per meter). Ini perkiraan, hasil nyata dipengaruhi cahaya dan kualitas kamera. Kerucut belum terhalang dinding, jadi pakai Batasi jarak untuk area yang tertutup tembok. Sudut lensa juga perkiraan, cek datasheet kamera.

Dua jari: perbesar, perkecil, dan geser. Satu jari di area kosong: geser. Di komputer: roda mouse untuk zoom. Ketuk zona warna untuk menampilkan atau menyembunyikan.
